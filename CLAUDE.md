# MoMask Semantic Spectrum — Project State

## What This Branch Does

Adds a semantic motion transformation pipeline on top of MoMask (HumanML3D + RVQVAE + MaskTransformer + ResidualTransformer). The core idea: condition the transformers on structured spectrum labels like `[walk:0.90][dance:0.10]` instead of only free-form text captions.

Original HumanML3D captions are never modified. Synthetic spectrum captions are written alongside them. At training time, 50% of sampled captions are spectrum captions and 50% are originals.

## Spectrum Dimensions

8 independent dimensions (NOT softmax — a motion can score high on multiple):

`walk`, `run`, `jump`, `dance`, `stand`, `gesture`, `spin`, `crouch`

Caption format: `[walk:0.90][dance:0.10] A person walks forward.`

## Training Sequence

### Step 1 — VQ Tokenizer (no spectrum conditioning, trains on 263-dim vecs)
```
python train_vq.py --dataset_name t2m --name RVQVAE --gpu_id 0
```
Checkpoint saved to `checkpoints/t2m/RVQVAE/model/`. FID eval skipped (evaluator checkpoint not downloaded).

### Step 2 — Masked Transformer (spectrum-conditioned)
```
python train_t2m_transformer.py \
  --dataset_name t2m \
  --name MaskTransformer \
  --vq_name RVQVAE \
  --gpu_id 0
```

### Step 3 — Residual Transformer (spectrum-conditioned)
```
python train_res_transformer.py \
  --dataset_name t2m \
  --name ResTransformer \
  --vq_name RVQVAE \
  --gpu_id 0
```

## Re-Augment (if needed)

To regenerate synthetic captions (e.g., after calibration fix):
```
python scripts/run_spectrum_pipeline.py \
  --motion_dir dataset/HumanML3D/new_joints \
  --text_dir   dataset/HumanML3D/texts \
  --out_dir    semantic_spectrum_data \
  --fit_calibration \
  --n_synthetic 3 \
  --overwrite
```

## Key Design Decisions

- Analyzer operates on raw `(T, 22, 3)` joints — no dependency on HumanML3D 263-dim preprocessing
- Foot contact detected from ankle/toe height above floor + velocity threshold (no binary labels needed)
- Spin detected via hip-line azimuth `arctan2` + `np.unwrap` before differencing (handles wraparound)
- `synthetic_prob=0.5` in dataset loader — half of training captions are spectrum-conditioned
- Token ordering is alphabetical and stable: small score delta → small string delta → smooth CLIP embedding shift
- CLIP processes the caption string directly; the token field in `.txt` is only used by legacy loaders
